# References

Drop example clips, audio, screenshots and storyboards here. Nothing in this
folder is used by the renderer; it is source material for new skits.

Uploading from the GitHub website (works on a phone browser too):

1. Open the repo on github.com and switch to the working branch
   (`claude/stick-figure-animations-tzkvae`) with the branch dropdown.
2. Open this `references/` folder, then **Add file → Upload files**.
3. Pick the files and commit.

Limits (per GitHub's docs): 25 MiB per file through the browser, up to 100
files at once; up to 100 MiB per file with git on the command line; larger
files need Git LFS. If a screen recording is too big, trim it to the part you
want, or upload just the audio.

Suggested layout: one folder per idea, e.g. `references/power-nap/` with the
clip plus a `notes.md` saying who says which line.
